# عيادة لوما لطب وتجميل الأسنان | LUMA CLINIC

موقع تعريفي ونظام حجز رقمي متكامل من صفحة واحدة (Single-Page Application) لعيادة الأسنان والتجميل الخيالية **"عيادة لوما" (LUMA CLINIC)** في بغداد. تم تصميم الموقع ليعكس هوية طبية راقية ومطمئنة بمعايير الجودة العالمية، مع دعم كامل للغة العربية والاتجاه من اليمين إلى اليسار (Full RTL).

---

## 🌟 الهوية البصرية (Visual Identity)
- **الحالة المزاجية (Mood):** هادئ، مطمئن، طبي حديث وفاخر، موثوق ومركّز على راحة المراجع بدون ألم.
- **الألوان المعتمدة:**
  - خلفيات ناصعة وألوان نعناعية فائقة اللطف: `#FFFFFF` و `#F1F8F6` (`mint-100`)
  - اللون الأساسي للنصوص والأزرار: تيل عميق `#0F5E5A` (`teal-700`)
  - لون اللمسات التجميلية: أكوا هادئ `#8FD3C8` (`mint-500` / `aqua`)
  - حدود ناعمة وظلال خفيفة: `#E2EFEA` وحواف دائرية `rounded-3xl` (24px)
- **الخطوط (Typography):**
  - خط العناوين والنصوص العربية: **IBM Plex Sans Arabic** و **Tajawal**
  - الخط الإنجليزي للمصطلحات: **Plus Jakarta Sans**
- **الأيقونات:** أيقونات خطية دقيقة وحديثة من مكتبة `lucide-react`.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)
- **Vite** + **React 19** + **TypeScript**
- **Tailwind CSS v3** (مع تخصيص ألوان لوما وهوامش الـ 24px)
- **Framer Motion** للتحريكات الهادئة والانسدال السلس
- **Canvas-Confetti** للاحتفال عند إتمام الحجز المبدئي
- **Lucide React** للأيقونات الطبية والخطية
- بدون خلفية برمجية (Serverless / Static-first)، جميع البيانات منظمة في `src/data/clinicData.ts`
- جاهز للنشر المباشر بنقرة واحدة على **Vercel** أو **Netlify** أو **Cloudflare Pages**.

## 📐 هيكلية الصفحة وأقسامها (Page Structure)

1. **الترويسة المثبتة (Sticky Header):**
   - شعار العيادة الثنائي (LUMA CLINIC | عيادة لوما)
   - روابط تنقل سريعة مع تأثير التمرير الناعم (Smooth Scroll)
   - زر مباشر للاتصال الهاتفي السريع وزر "احجز الآن"
   - قائمة سريعة متجاوبة للأجهزة الذكية (Mobile Drawer).

2. **الواجهة الرئيسية (Hero Section):**
   - شارة الاعتماد الطبي في بغداد
   - العنوان الرئيسي الجذاب: `"ابتسامتك تستحق الأفضل دائماً"`
   - نص ترحيبي يركز على الراحة والتكنولوجيا الحديثة
   - أزرار العمل: "احجز موعدك الآن" و "تعرّف على خدماتنا"
   - مؤشرات الثقة الفورية: +12,000 مراجع سعيد، تقييم 4.9/5 على Google
   - صورة بورتريه لابتسامة طبيعية مشرقة بقناع بيضاوي مع بطاقات تفاعلية طافية.

3. **شريط الثقة والإحصائيات (Trust Bar):**
   - 4 إحصائيات مع عداد تصاعدي رقمي ناعم (Count-up Animation):
     - `+15` سنوات خبرة
     - `+12,500` مريض وابتسامة سعيدة
     - `+8` استشاريين وأخصائيين معتمدين
     - `100%` تقنيات رقمية ثلاثية الأبعاد (3D CBCT).

4. **الخدمات التخصصية (Services):**
   - 6 بطاقات خدمات مع أيقونات خطية راقية:
     1. تبييض الأسنان بالليزر
     2. زراعة الأسنان الرقمية الموجهة
     3. تقويم الأسنان الشفاف والمرئي
     4. ابتسامة هوليوود (فينير ولومينير)
     5. تنظيف وفحص دوري شامل
     6. فيلر وبوتوكس تجميلي للوجه والابتسامة
   - النقر على أي خدمة يفتح **نافذة تفاصيل موسعة (Detail Modal)** تعرض: مدة الجلسة، فترة التعافي، خطوات الإجراء في العيادة، ولمن يناسب، مع زر حجز فوري يحدد الخدمة مسبقاً.

5. **شريط المقارنة التفاعلي (Before / After Slider):**
   - سلايدر سحب تفاعلي (Drag comparison slider) باللمس أو الماوس لمقارنة الصور قبل وبعد
   - 3 حالات علاجية حقيقية قابلة للتبديل:
     - ابتسامة هوليوود وعدسات E-Max
     - تبييض الأسنان بالليزر المتقدم
     - التقويم الشفاف الرقمي
   - تفاصيل مدة العلاج واسم الطبيب المشرف وقصة الحالة.

6. **فريق الأطباء (Our Doctors):**
   - 3 بطاقات للأطباء الاستشاريين (د. سارة العبيدي، د. حيدر الشمري، د. ريم الدليمي)
   - صور احترافية، التخصص الدقيق، سنوات الخبرة، الشهادات والعضويات، أيام التواجد
   - زر مباشر لطلب استشارة يحدد الطبيب تلقائياً في نموذج الحجز.

7. **رحلة العلاج (How It Works):**
   - جدول زمني مرئي من 4 خطوات واضحة لإزالة القلق:
     1. استشارة أولية واستماع باهتمام
     2. تشخيص رقمي ومسح ثلاثي الأبعاد
     3. علاج دقيق ومريح خالٍ من الألم
     4. متابعة مستمرة وضمان جودة معتمد.

8. **آراء المراجعين (Testimonials Carousel):**
   - سلايدر تلقائي ناعم يتنقل كل 6 ثوانٍ مع إمكانية الإيقاف عند التمرير
   - 4 مراجعات واقعية من مراجعين موثقين، مع نجوم التقييم وتفاصيل الإجراء المنفذ.

9. **نموذج الحجز متعدد الخطوات (Multi-step Booking Form):**
   - مؤشر تقدم مرئي من 3 خطوات واضحة:
     - **الخطوة 1:** اختيار الخدمة المطلوبة + تحديد الطبيب المفضل
     - **الخطوة 2:** اختيار تاريخ الزيارة والفترة الزمنية (صباحية / مسائية) وساعة الموعد
     - **الخطوة 3:** الاسم الكامل ورقم الهاتف والملاحظات مع تحقق فوري من صحة الحقول (Validation)
     - **الخطوة 4 (شاشة التأكيد):** ملخص الحجز + تأثير احتفالي (Confetti) + زر فوري للتأكيد عبر **WhatsApp (`wa.me`)** مع رسالة عربية منسقة وجاهزة للإرسال!

10. **الأسئلة الشائعة (FAQ Accordion):**
    - 6 أسئلة طبية وجوهرية مع إجابات مطمئنة وتوسيع وطي ناعم (Accessible Accordion)
    - صندوق تواصل سريع مع الاستشاري المناوب عبر الواتساب.

11. **التواصل والتذييل (Contact & Footer):**
    - عنوان العيادة في بغداد (المنصور - شارع الأميرات - مجمع النخبة الطبي)
    - أوقات الدوام الرسمية وخط الطوارئ السريع
    - بطاقة تفاعلية لموقع العيادة مع رابط مباشر لخرائط Google
    - روابط سريعة، منصات التواصل الاجتماعي، معايير التعقيم وإخلاء المسؤولية الطبية.

12. **العناصر العائمة:**
    - زر واتساب عائم في الزاوية اليسرى مع وميض وتنبيه مباشر للتحدث مع المنسق الطبي
    - زر الرجوع إلى أعلى الصفحة (Back to Top) يظهر بسلاسة عند التمرير.

## 🚀 تعليمات التشغيل والبناء (Run Instructions)

### 1. المتطلبات الأساسية
- تثبيت [Node.js](https://nodejs.org/) (الإصدار 18 أو أحدث)

### 2. تثبيت الحزم
افتح موجه الأوامر في مجلد المشروع ونفّذ:
```bash
npm install
```

### 3. تشغيل وضع التطوير المحلي (Dev Server)
```bash
npm run dev
```
سيعمل الموقع على الرابط المحلي: `http://localhost:5173/`

### 4. بناء المشروع للإنتاج (Production Build)
```bash
npm run build
```
سيتم إنشاء ملفات الويب الجاهزة والمحسنة داخل مجلد `dist/`.

### 5. معاينة النسخة النهائية محلياً (Preview)
```bash
npm run preview
```

## 🚢 النشر على Vercel (Deployment)

المشروع جاهز ومُهيأ بالكامل للنشر الفوري على منصة **Vercel**:

### الطريقة الأولى: عبر Vercel CLI
```bash
npm install -g vercel
vercel
```

### الطريقة الثانية: عبر لوحة تحكم Vercel ومستودع GitHub
1. ارفع المشروع إلى مستودع على GitHub.
2. توجّه إلى [Vercel Dashboard](https://vercel.com/dashboard) واضغط **"Add New Project"**.
3. استورد المستودع (Import Repository).
4. سيتعرف Vercel تلقائياً على إعدادات Vite:
   - **Framework Preset:** Vite
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
5. اضغط **Deploy**.

## ♿ الجودة وإمكانية الوصول (Accessibility & SEO)
- وسم اللغة والاتجاه: `lang="ar" dir="rtl"` على مستوى الصفحة بالكامل.
- تباين ألوان يتوافق مع معايير **WCAG AA** لسهولة القراءة والراحة البصرية.
- حلقات تركيز واضحة (`:focus-visible`) للتنقل عبر لوحة المفاتيح.
- وسوم صور كاملة (`alt`) ووصف نصوص دقيق.
- وسوم البيانات الوصفية الغنية (Meta Tags, Open Graph) لمشاركة الروابط باحترافية على وسائل التواصل الاجتماعي.
